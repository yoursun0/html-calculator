# 小算盤

靜態小算盤 POC。無 framework，無 build。用瀏覽器開 `index.html` 即可。

## 本地開啟

在這個資料夾：

```bash
python3 -m http.server 8766
```

然後開 `http://127.0.0.1:8766/`。直接雙擊 `index.html` 也可以。

## 模式

點左上角選單（開始時收埋）。

- **標準**：加減乘除、小數、正負、百分比、倒數、平方、平方根、記憶。
- **進階**：標題變成 **科學**。保留基本鍵，另有括號、π、e、三角函數（可 inv 切倒數）、log、ln、x^y、10^x、n!、abs、DEG/RAD（預設 DEG）。

點選單再開可收起；點選單外面會收；揀完模式都會收。

## CE 同 C

- **CE** 只清而家輸入緊嘅數字，未完成嘅運算保留。
- **C** 清全部運算（包括未完運算同括號），顯示回到 0。記憶要用 **MC** 先清。

## 例子

- `2` `+` `3` `=` → 5
- `200` `+` `10` `%` `=` → 220
- `10` `MS`，`C`，`MR` → 10
- 進階、DEG：`30` `sin` → 0.5
- `(` `2` `+` `3` `)` `×` `4` `=` → 20

非法輸入同除以零都會顯示 `Error`。
