# 小算盤用法

## 打開

1. 開這個 repo 的資料夾。
2. 用瀏覽器開 `index.html`，或執行 `python3 -m http.server 8766` 再開 `http://127.0.0.1:8766/`。
3. 畫面標題係 **小算盤**。顯示一開始係 `0`。

## 標準模式

標題顯示 **標準**。左上角 ☰ 先收埋。

可以撳：

- 數字 `0–9`、小數點 `.`、`+/−`
- `+` `−` `×` `÷` 然後 `=`
- `%`：如果前面係加或減，百分號係對第一個數計（`200 + 10%` 等於 220）
- `1/x`、`x²`、`²√x`
- `⌫` 刪最後一個字
- **CE**：清而家呢次輸入，未完成運算仲在
- **C**：清運算同顯示，回到 0
- 記憶：**MS** 存而家數字，**MR** 讀出，**M+** / **M−** 加減入記憶，**MC** 清記憶

## 科學

喺選單揀 **科學**。基本鍵仍然在，另外：

- `(` `)` 括號
- `π`、`e`
- `sin` `cos` `tan`；`inv` 會切去 `sin⁻¹` `cos⁻¹` `tan⁻¹`
- `log`（以 10 為底）、`ln`
- `x^y`、`10^x`、`n!`、`abs`
- **DEG / RAD**，預設 DEG

選單會喺揀完模式後收埋。再撳 ☰ 可以開同關。撳選單外面都會收。

## 錯誤

除以零、負數開方、log/ln 非正數、階乘唔係 0 或正整數，都會顯示 `Error`。再撳數字或 `C` / `CE` 可以繼續。

## 例子

1. 加：撳 `2` `+` `3` `=`，顯示 5。
2. 百分比：撳 `200` `+` `10` `%` `=`，顯示 220。
3. 記憶：撳 `10` `MS`，`C`，`MR`，顯示 10。
4. 正弦：切去科學，確認係 DEG，撳 `30` `sin`，顯示 0.5。
5. 括號：撳 `(` `2` `+` `3` `)` `×` `4` `=`，顯示 20。
